OPS 怎么启动 / 关闭 HTML 服务 ▶

启动（让他人能访问）

关键：--bind 0.0.0.0，否则默认只本机能访问
# 方式一：Python 自带（机器上一般有 python3） cd /data/workspace/trpc-agent-go/docs/notes python3 -m http.server 8000 --bind 0.0.0.0 # 方式二：Node 的 serve（更稳，带目录索引、缓存友好） cd /data/workspace/trpc-agent-go/docs/notes npx serve@latest -l 8000 # serve 默认监听所有网卡

启动后，把 http://<本机IP>:8000/ 告诉同事。查本机 IP： hostname -I | awk '{print $1}'（当前机器是 21.6.70.193，但 IP 可能变，以实时查为准）。 若机器有防火墙 / 云安全组，需放行对应端口。仅内网分享用，不要把无鉴权的静态服务长期暴露公网。

关闭

前台跑就 Ctrl+C；后台跑用下面方法
# 方法 A：按端口直接杀（最省事） pkill -f "http.server 8000" # python 方式 pkill -f "serve -l 8000" # node 方式 # 方法 B：先看 PID 再精确杀（更稳） pgrep -af "http.server 8000" # 输出形如: 1234567 python3 -m http.server 8000 --bind 0.0.0.0 kill <上面那个 PID> # 验证已关闭（连不上 = 已关闭） curl -s -o /dev/null -w "%{http_code}\n" --max-time 2 http://0.0.0.0:8000/ || echo "已关闭"
DEV 怎么新增一个入口 ▶

怎么新增一个入口

给后续维护者

每份报告就是一个独立的 .html 文件，放在 docs/notes/ 下。 导航页的入口卡片由本页底部的 REPORTS 数组渲染——新增报告只需在数组里加一项， 不用改 HTML 结构。加完刷新本页，新卡片就出现了。

// 在本文件底部找到 REPORTS 数组，加一项： { id: 'your-report', // 唯一标识，也作卡片锚点 figNo: 'FIG. 03', // 图框编号，顺延即可 kind: '主题分类', // 卡片头部的分类标签 title: '报告标题', // 卡片主标题 sub: '英文/技术副标题', // 蓝色小字副标题 blurb: '一两句话讲这份报告讲什么', tags: ['标签1', '标签2'], // 关键词标签 file: 'your-report.html', // 同目录下的报告文件名 date: '2026-07-08', // 核实日期 }

建议同步把源笔记（.md）写进 docs/notes/README.md 索引，保持 Markdown 与可视化两套入口都不缺。
